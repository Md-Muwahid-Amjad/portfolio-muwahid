## 📌 Overview

This repository hosts the source code for my personal **AWS Cloud Portfolio**, built to showcase my technical background, core cloud competencies, and hands-on infrastructure projects. 

The website is designed with a dark, high-contrast engineering aesthetic and optimized for fast performance, accessibility, and responsiveness across all devices.

## ✨ Features

- **Responsive Modern UI:** Mobile-first, flexbox/grid layout styled with a developer-focused dark theme.
- **Skills Grid:** Visual badges for core AWS cloud services (EC2, S3, VPC, IAM, EBS, ALB, CloudWatch, Linux).
- **Project Showcase:** Highlights hands-on cloud labs and infrastructure deployments with clear problem-solving narratives.
- **Fast & Lightweight:** Built using clean semantic HTML5 and vanilla CSS3 without heavy external dependencies.
- **Continuous Deployment:** Hosted on Vercel with automatic edge delivery and global CDN caching.

## 💻 Local Development

To run this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Md-Muwahid-Amjad/portfolio-muwahid.git
   cd portfolio-muwahid
   ```

2. **Open the project:**
   - Double-click `index.html` to open it in your default web browser, OR
   - Run a lightweight local server:
     ```bash
     # Using Python:
     python3 -m http.server 8000
     
     # Or using Node.js:
     npx serve .
     ```

3. **View in browser:**
   Navigate to `http://localhost:8000`
